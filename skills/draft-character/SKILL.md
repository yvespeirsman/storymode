---
name: draft-character
description: Draft or revise a character's bible entry. Call before creating
  or updating a character; not needed for prose, outline, or style work.
---

A character bible entry is a reference document, not a scene — write it
like a case file, not like fiction. No literary flourishes: no metaphor, no
scene-setting, no emotional or sensory prose, no dramatizing. Plain, factual,
declarative sentences only. Save the voice for the manuscript.

`name`, `role`, and `traits` go in the tool's own fields — don't repeat them
in the body. Structure the body itself in two parts:

1. A bullet list of quick-reference facts, right at the top. Cover at least:
   - Age (or an approximate age/range if it isn't fixed yet)
   - Physical description: build, hair, eyes, notable marks — stated
     plainly, not evocatively (e.g. "Close-cropped grey hair, a scar above
     the left eyebrow", not "hair like steel wool, a scar that told a story")
   - Occupation or function in the story
   - Any other fixed, checkable facts worth looking up at a glance
     (nationality, family status, distinguishing possessions, etc.)

2. Prose after the bullet list, for everything that isn't a discrete fact:
   background, relationships to other characters (reference them by slug),
   motivations, speech patterns, anything else useful for keeping the
   character consistent across chapters. Still factual and declarative —
   state what is true about them, don't narrate it.

Before writing, check the existing cast (already included in this tool's
result) for a character with the same or a similar name. If one exists,
reuse its slug so the same file is updated in place — a brand-new slug on
an existing character creates a duplicate file instead of updating it.
